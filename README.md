Token Radar v5 — every pre-token protocol ranked by implied value, with a costed farm plan for each. The board covers all 40 watchlist protocols plus 157 early pre-token protocols below the watchlist floor, scored by a fitted market multiple: each category's median mcap/TVL across 118 live-token comparables, shrunk toward the universe median (prior strength 8), with a family → universe → constant fallback ladder. Wrapped, staked and bridged products of tokens that already trade are not ranked. Every row carries the evidence behind its number and a one-sentence argument for its rank, and every farm plan states its whole budget (capital + per-chain gas).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```
